# ChessTrainer UI

React + TypeScript прототип пользовательского сценария первого milestone.

Для знакомства с кодом: [React для C#-разработчика](REACT_GUIDE.md).

## Что уже работает

- адаптивный интерфейс в формате шахматного приложения без маркетингового landing;
- ввод Chess.com username с явно помеченной заглушкой;
- загрузка одиночного `.pgn` и извлечение основных тегов/ходов в браузере;
- список партий;
- отдельные вкладки «Партия» и «Анализ», причём партия открывается первой;
- воспроизведение позиции при выборе любого хода;
- легальные ручные ходы перетаскиванием или выбором двух полей;
- пользовательская линия варианта с возможностью сброса;
- вкладка «Играть»: ручная игра за обе стороны, отмена одного полухода, переворот доски;
- рокировка, взятие на проходе и выбор фигуры при превращении;
- экспорт стандартного PGN с результатом партии;
- локальное сохранение в списке партий и восстановление черновика после перезагрузки;
- вертикальная шкала слева: без оценки, явно помечена DEMO до подключения Stockfish;
- заглушки анализа и тренера без имитации вычислений.

Chess.com, Stockfish, SignalR и LLM пока не вызываются. Демо-данные находятся в `src/data/mock.ts`. Доску отображает `react-chessboard` (MIT), подключённый через `src/components/ChessBoard.tsx`. Это замена `react-chessboard-ui`; правила не зависят от UI-библиотеки. PGN и правила ходов обрабатывает `chess.js` с BSD-2-Clause лицензией.

## Следующая граница интеграции

Не переносить шахматный анализ в браузер. После появления .NET API заменить заглушки на небольшой typed API client:

- `GET /api/players/{username}/games`;
- `POST /api/games/import/pgn`;
- `POST /api/games/{gameId}/analysis`;
- `GET /api/analysis-jobs/{jobId}`;
- SignalR-события прогресса analysis job.

Канонический PGN parsing также должен выполняться backend. Клиентский parser нужен только для быстрого preview.

## Локальная партия и сохранение

`src/lib/localGame.ts` воспроизводит ходы и экспортирует PGN. `src/data/localGames.ts` — отдельный локальный адаптер хранения, который позже заменяется API-клиентом. Данные остаются только в браузере; очистка его хранилища удалит локальные партии. Экспорт PGN позволяет сохранить их отдельно. Локальный компьютерный соперник удалён. Звуки взяты из `sounds/public/sound/standard` и скопированы в `frontend/public/sound/standard`: `Move.mp3` для хода, `Capture.mp3` для взятия, `OutOfBound.ogg` для шаха, `GenericNotify.mp3` для мата (отдельного файла мата в наборе нет). Воспроизведение использует браузерный Audio без дополнительных зависимостей. Переключатель сохраняет настройку в браузере; звук воспроизводится только после принятого ручного хода, при шахе — вместо звука хода или взятия, при мате — звук завершения с приоритетом над шахом.

Проверка правил и PGN (Node.js 22.18+ с поддержкой TypeScript):

```bash
npm test
```
